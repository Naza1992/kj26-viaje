# Corea + Japon 2026

Itinerario de viaje como app instalable (PWA). Funciona sin conexion.

Los datos sensibles (QR de pasajes y direcciones de alojamiento) estan cifrados
con AES-GCM 256 y solo se descifran en el dispositivo con la passphrase correcta.

Generado desde el repositorio privado `corea-japon-2026-itinerary`.
